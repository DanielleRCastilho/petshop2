PET SHOP AMIGO FIEL

SOBRE O PROJETO:
Este projeto foi desenvolvido como parte de uma atividade acadêmica, com o objetivo de praticar os conceitos de CRUD (Create, Read, Update e Delete) utilizando a linguagem Python e um banco de dados.

A aplicação permite realizar operações básicas de cadastro, consulta, atualização e exclusão de registros.

FUNCIONALIDADES:
Cadastrar: adicionar novos registros ao banco de dados.
Consultar: visualizar os registros cadastrados.
Atualizar: modificar informações existentes.
Excluir: remover registros do banco de dados.

COMO EXECUTAR O PROJETO:
Clone este repositório:
bash
git clone URL_DO_REPOSITORIO

Entre na pasta do projeto:
bash
cd nome-do-projeto

Execute o arquivo principal:
bash
python main.py

OBJETIVO:
Projeto desenvolvido para fins educacionais, visando colocar em prática os conceitos de manipulação de dados, conexão com banco de dados e implementação das operações CRUD utilizando Python.
